# 口說亂鬥 Speak Brawl

雅思口說遊戲化練習網頁（目標 Band 6.5+），以《24 天英語口說奇蹟》講義與《雅思口說教戰手冊》音檔內容為題庫（網頁需密碼進入）：

| 模式 | 對應 | 內容 |
|---|---|---|
| 寶石爭奪 | Part 1 · AYE | 5 題快問快答，每題 30 秒 |
| 荒野單挑 | Part 2 · MIDY | 1 分鐘準備＋2 分鐘獨白 |
| 金庫攻防 | Part 3 | 3 道深度討論題 |
| 亂鬥足球 | 改寫技巧 | 3×3×3、委婉、Re-shuffling、SEP |
| 賞金對決 | 情境對話 | Day 7–24 對話角色扮演 |
| 熱區佔領 | 發音 | Day 1–6 發音詩跟讀 |
| 訓練洞窟 | 詞彙 | 九大情境 Word Bank 517 詞 |
| 教戰手冊題庫 | Part 1/2/3 | 《雅思口說教戰手冊》音檔整理 195 題＋範例答案 |

- 使用瀏覽器 Web Speech API 語音辨識（建議電腦版 Chrome／Edge），不支援時可改打字。
- 估計 Band 為練習參考值，非官方評分；每場可複製 AI 批改指令到 ChatGPT／Claude。
- 進度存在瀏覽器 localStorage。
